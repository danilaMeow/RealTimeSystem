# RealTimeSystem
# Классификация и анализ параметров системы реального времени
Вариант: **медицинский монитор**.


Программа читает описание набора задач из JSON-файла и считает для них основные параметры системы реального времени (СРВ): запас времени, тип дедлайна, класс системы, критическую задачу, требуемое время реакции и коэффициент загрузки процессора.

## Что умеет программа

- считает запас времени задачи `L = D - C` и проверяет выполнимость (`L >= 0`);
- определяет тип дедлайна:
  - `D = T` — неявный,
  - `D < T` — ограниченный,
  - `D > T` — произвольный;
- определяет класс системы: жёсткого РВ, если есть хотя бы одна жёсткая задача, иначе мягкого;
- находит критическую задачу — жёсткую с минимальным запасом `L`;
- вычисляет требуемое время реакции `R_треб` — минимальный `D` среди жёстких задач (если жёстких нет — среди всех);
- считает коэффициент загрузки `U = Σ(C_i / T_i)` и проверяет условие `U <= 1`;
- определяет архитектурный класс: однопроцессорная, многопроцессорная или распределённая (если есть сеть).

## Запуск

Нужен Python 3.8+, сторонние библиотеки не требуются. Запускать из корня проекта (иначе не сработают импорты `src.*`):

```
python -m src.main
```

## Формат входных данных

Файл `data/tasks.json`:

| Поле | Описание |
|---|---|
| `system_info.n_cpu` | число процессоров |
| `system_info.has_network` | есть ли сеть (`true` / `false`) |
| `tasks[].name` | название задачи |
| `tasks[].hardness` | класс задачи: `жёсткое`, `твёрдое` или `мягкое` |
| `tasks[].C` | время выполнения, мс |
| `tasks[].D` | относительный дедлайн, мс |
| `tasks[].T` | период, мс |

## Исходные данные варианта

| Задача | Класс | C (мс) | D (мс) | T (мс) |
|---|---|---|---|---|
| Контроль сердечного ритма | Жёсткое | 1.0 | 5.0 | 5.0 |
| Тревога по порогу | Жёсткое | 2.0 | 10.0 | 10.0 |
| Обновление экрана | Мягкое | 4.0 | 20.0 | 20.0 |
| Запись в архив | Мягкое | 30.0 | 500.0 | 500.0 |

## Результаты

- Запас времени `L`: 4.0 / 8.0 / 16.0 / 470.0 мс — все задачи выполнимы.
- Тип дедлайна: неявный (`D = T`) для всех задач.
- Класс системы: жёсткого реального времени.
- Архитектура: однопроцессорная (`n_cpu = 1`, без сети).
- Критическая задача: «Контроль сердечного ритма» (`L = 4.0` мс).
- Требуемое время реакции `R_треб` = 5.0 мс.
- Коэффициент загрузки `U = 0.6600 <= 1`, система не перегружена.

## Модули

- `models.py` — класс `Task` (`name`, `hardness`, `C`, `D`, `T`).
- `analyzer.py` — функции `slack`, `is_feasible`, `deadline_type`, `classify_system`, `critical_task`, `required_reaction_time`, `utilization`, `classify_architecture`.
- `main.py` — `load_data` читает JSON, `main` выводит таблицу задач и итоговое заключение по системе.
