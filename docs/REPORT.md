* **Запас времени (L = D - C):**

  * Тревога по порогу: 10.0 - 2.0 = 8.0 мс (L >= 0, выполнимо)
  * Обновление экрана: 20.0 - 4.0 = 16.0 мс (L >= 0, выполнимо)
  * Запись в архив: 500.0 - 30.0 = 470.0 мс (L >= 0, выполнимо)
* **Типы дедлайнов:** Неявные (D = T) для всех задач.
* **Класс системы:** Система жёсткого реального времени (наличие жёстких задач).
* **Архитектурный класс:** Однопроцессорная система (n_cpu = 1, без сети).
* **Критическая задача:** Контроль сердечного ритма (L = 4.0 мс).
* **Требуемое время реакции (R_треб):** 5.0 мс.
* **Коэффициент загрузки (U):** 0.6600 <= 1.0 (условие выполнено, система не перегружена).
